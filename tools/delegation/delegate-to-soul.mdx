In V1 this tool was called `delegate_to_soul`. In V2 it is `delegate_to_agent`. The behaviour is the same: Prime calls this tool to hand off a task to a specialist agent, waits for the result, and incorporates it into the final response.

See [Agent Delegation →](/qors/delegation) for how delegation works and how to configure it.

The `read_document` tool reads files and returns their content in a structured form the agent can work with. Upload a contract, report, or spreadsheet and the agent can summarise, extract data, or answer questions from it directly.

## Supported file types

| Format | Notes |
|--------|-------|
| PDF | Text PDFs and scanned PDFs (via OCR) |
| Word (DOCX) | Headings, paragraphs, tables, lists |
| Excel (XLSX) | All sheets; numbers preserved |
| CSV | Parsed as tabular data |
| Plain text (TXT, MD) | Read as-is |

## What it extracts

The tool doesn't just dump raw text — it preserves document structure:

- **Headings and sections** — the agent knows "this is the Introduction" vs "this is clause 4.2"
- **Tables** — extracted as structured data the agent can read and reason about
- **Lists** — bulleted and numbered lists are preserved
- **Metadata** — author, creation date, page count (where available)

For spreadsheets, each sheet is extracted separately. Column headers are used to label the data.

## OCR for scanned PDFs

If a PDF contains scanned images rather than text (a common problem with contracts and invoices), `read_document` applies OCR automatically. Quality depends on the scan resolution — clear 300dpi scans work well.

## Example uses

- **"Summarise this contract"** — the agent reads the DOCX and identifies key terms, dates, and obligations
- **"How much did we spend on marketing in Q3?"** — the agent reads the Excel report and finds the relevant numbers
- **"Extract all the line items from this invoice PDF"** — the agent reads the PDF and returns structured data
- **"Does this policy document mention data retention?"** — the agent searches the text and quotes the relevant section
- **"Compare these two proposals"** — the agent reads both files and synthesises a comparison

## How to use

Share a file in chat and ask your question. You can also ask the agent to read a file from storage:

> "Read the report in my storage folder and pull out the key findings."

## Inputs

| Parameter | Required | Description |
|-----------|----------|-------------|
| `file_path` | Yes (or `file_id`) | Path to the file in agent storage |
| `file_id` | Yes (or `file_path`) | ID of an uploaded file |
| `pages` | No | Specific pages to read (PDFs only), e.g. `"1-5"` |
| `sheet` | No | Sheet name or index (spreadsheets only) |

## Size limits

Files up to 50 MB are supported. For very large PDFs, use the `pages` parameter to read specific sections rather than the whole document.

Qorven agents can control a real Chromium browser running on your server. They can navigate to any URL, click buttons, fill in forms, interact with JavaScript-heavy pages, and extract data — all the things a human would do in a browser, but automatically.

## What agents can do with a browser

- **Log into web apps** — authenticate with username/password and continue working in the logged-in session
- **Fill and submit forms** — expense reports, CRM records, support tickets, data entry tasks
- **Click through UIs** — navigate multi-step wizards, approve requests, trigger actions
- **Scrape dynamic content** — extract data from pages that require JavaScript to render (React apps, SPAs, dashboards)
- **Download files** — trigger downloads and save the files to Drive for further processing
- **Take screenshots** — capture the state of a page at any point in a workflow

## Privacy and security

The browser runs on **your server**, not in the cloud. Any credentials you give an agent stay within your infrastructure — they are never sent to Anthropic or any third party.

<Warning>
  Browser tools that submit forms, click buttons, or change data on external sites require approval by default. Enable the Approvals panel in your workspace to review these actions before they execute.
</Warning>

## Requirements

Chromium must be installed on the host running Qorven. On Debian/Ubuntu:

```bash
apt-get install -y chromium-browser
```

Qorven will use the `CHROME_PATH` environment variable if set, or fall back to finding `chromium` / `chromium-browser` / `google-chrome` on `$PATH`.

Dreaming was a V1 feature that ran agents overnight to consolidate and reorganise their memories. In V2, this is handled automatically by memory compaction — agents compress long conversation histories into compact context blocks without any scheduled overnight process.

See [Memory Compaction →](/memory/compaction) for how agents consolidate context today.

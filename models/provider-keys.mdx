Provider keys connect Qorven to AI model providers. Without at least one key, agents can't do anything — a key is the first thing you configure after installation.

## Adding a key

<Steps>
  <Step title="Go to Settings → Provider Keys">
    Open the dashboard and navigate to **Settings → Provider Keys**.
  </Step>
  <Step title="Select the provider">
    Choose the provider from the list. If your provider isn't listed, use the **OpenAI-compatible endpoint** option — most modern providers support this format.
  </Step>
  <Step title="Paste your API key">
    Paste the key into the field. For providers that need additional configuration (region, endpoint URL, etc.), the form will prompt you for those values.
  </Step>
  <Step title="Save and verify">
    Click **Save**. Qorven immediately tests the key with a lightweight API call. A green checkmark confirms the key works. If it fails, check that you've copied the full key and that it has the necessary permissions.
  </Step>
</Steps>

Once saved, the provider's models become available in the [Models Hub](/models/overview) and can be assigned to agents.

## Key storage

Keys are encrypted at rest using AES-256 before being stored in the database. They are never logged, never included in audit log entries, and never returned in plaintext after being saved. If you need to update a key, overwrite it — you cannot retrieve the existing value.

## Multiple keys per provider

You can add more than one key per provider — useful if you have keys scoped to different projects, cost centers, or rate limit tiers. Each key gets a label. Assign specific keys to specific agents in the agent's configuration.

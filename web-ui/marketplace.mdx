The Marketplace is where you extend your agents' capabilities without writing code. Skills are reusable procedures — step-by-step instructions that tell an agent how to handle a specific type of task. Install a skill and your agents immediately know how to follow it.

## What a skill is

A skill is a structured procedure, not new software. Think of it as a trained workflow: "When asked to write a weekly report, gather data from these sources in this order, format it like this, and deliver it here."

Skills are written in plain language and live in your agents' instruction set. Installing a skill is similar to onboarding a new employee with a documented process — the agent reads the procedure and follows it.

## Browsing the Marketplace

Skills are organized by category:

- **Research** — web research workflows, competitor analysis, market monitoring
- **Writing** — content templates, email styles, report formats
- **Operations** — invoice processing, CRM updates, onboarding checklists
- **Development** — code review procedures, deployment checklists, debugging workflows
- **Communication** — meeting summary formats, Slack update templates, client briefing structures

Use the search box to find skills by name or keyword. Each skill listing shows:

- What it teaches the agent to do
- Which agents it's compatible with
- Author name and install count
- A preview of the skill instructions

## Installing a skill

<Steps>
  <Step title="Find a skill">
    Browse categories or search for the capability you need.
  </Step>
  <Step title="Review the skill">
    Read the skill description and preview the instructions to confirm it does what you need.
  </Step>
  <Step title="Click Install">
    Select which agent(s) should receive the skill, then click Install.
  </Step>
  <Step title="Confirm">
    The skill is added to the selected agents immediately. You can test it by asking the agent to perform the task the skill covers.
  </Step>
</Steps>

<Info>
  Installed skills are visible in each agent's configuration under the Skills tab. You can view, edit, or remove any skill from there.
</Info>

## Modifying installed skills

After installing, you can customize any skill for your context — change the output format, adjust the data sources, or add steps. Go to the agent's configuration page and click the skill name to open the editor.

Your edits do not affect the original Marketplace listing or other users.

## Sharing your own skills

If you've built a skill that works well and would benefit others, you can publish it to the Marketplace. From your agent's Skills tab, click **Share to Marketplace** on any skill, add a description, and submit for review.

<Tip>
  The most useful community skills tend to be highly specific — "process inbound freelancer invoices" rather than "handle email." The narrower the procedure, the more reliably agents follow it.
</Tip>

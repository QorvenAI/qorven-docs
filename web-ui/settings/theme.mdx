The Theme settings control how Qorven looks. Changes apply immediately — no save button required.

## Color mode

| Mode | Behavior |
|---|---|
| **Dark** | Dark backgrounds across all pages (default) |
| **Light** | Light backgrounds |
| **System** | Follows your operating system's dark/light mode setting |

Click a mode to switch immediately.

## Accent color

Choose the highlight color used for buttons, active states, and links. Select from the preset palette or enter a custom hex code.

The accent color affects:
- Primary buttons
- Active sidebar items
- Link text
- Focus rings on inputs
- Toggle and checkbox colors

## Font size

| Size | Description |
|---|---|
| **Small** | 13px base — fits more content on screen |
| **Medium** | 15px base — default |
| **Large** | 17px base — easier reading on high-DPI screens |

## Layout density

| Density | Description |
|---|---|
| **Comfortable** | More padding between elements — default |
| **Compact** | Tighter spacing — fits more items in lists and tables |

Compact mode is useful on smaller screens or if you prefer a denser information display.

## More appearance settings

Theme only covers visual appearance. For language, timezone, and notification preferences, see [Preferences](/web-ui/settings/preferences).

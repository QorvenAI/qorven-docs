The main configuration file lives at `/etc/qorven/config.toml` for systemd installs and `~/.qorven/config.toml` for development installs. Every key can also be set via [environment variable](/reference/environment-vars).

## `[server]`

Controls the HTTP server.

| Key | Type | Default | Description |
|---|---|---|---|
| `port` | int | `4200` | Port the server listens on |
| `host` | string | `"0.0.0.0"` | Interface to bind to; use `"127.0.0.1"` to restrict to loopback |
| `log_level` | string | `"info"` | Log verbosity: `"debug"`, `"info"`, `"warn"`, `"error"` |
| `web_dir` | string | `""` | Path to compiled frontend assets; empty = use embedded assets |
| `request_timeout` | duration | `"120s"` | Maximum duration for a single HTTP request |
| `max_body_size` | string | `"32MB"` | Maximum request body size |

## `[database]`

PostgreSQL connection settings.

| Key | Type | Default | Description |
|---|---|---|---|
| `url` | string | — | Full connection string: `postgres://user:pass@host:5432/dbname?sslmode=disable` |
| `pool_min` | int | `2` | Minimum number of idle connections in the pool |
| `pool_max` | int | `20` | Maximum number of open connections |
| `pool_idle_timeout` | duration | `"10m"` | Close idle connections after this duration |
| `migration_auto` | bool | `true` | Run pending migrations on startup |

## `[security]`

Encryption and network security.

| Key | Type | Default | Description |
|---|---|---|---|
| `encryption_key` | string | — | Base64-encoded 32-byte AES-256-GCM key. **Required.** Generated by installer. |
| `ssrf_allowlist` | []string | `[]` | Domain patterns agents may contact outbound; empty = block all external requests from agents |
| `ssrf_block_private` | bool | `true` | Block requests to RFC-1918 / loopback / link-local from agent tool calls |

## `[auth]`

Authentication and session settings.

| Key | Type | Default | Description |
|---|---|---|---|
| `token` | string | — | Master bearer token for single-tenant mode. **Required** in single-tenant. |
| `jwt_secret` | string | — | Secret for signing JWT session tokens. Generated by installer. |
| `jwt_expiry` | duration | `"168h"` | JWT token lifetime (default: 7 days) |
| `multi_tenant` | bool | `false` | Enable multi-tenant mode with PostgreSQL RLS |
| `login_max_attempts` | int | `5` | Failed attempts before account lockout |
| `login_lockout` | duration | `"15m"` | Duration of account lockout after max failed attempts |
| `login_rate_limit` | int | `10` | Maximum login attempts per minute per IP |

## `[ui]`

Branding and UI customization.

| Key | Type | Default | Description |
|---|---|---|---|
| `name` | string | `"Qorven"` | Workspace name shown in the UI and page title |
| `logo_url` | string | `""` | URL or path to a custom logo image |
| `theme` | string | `"dark"` | Default theme: `"dark"` or `"light"` |

## `[tls]`

TLS certificate configuration. See [TLS best practices](/security/tls-best-practices) for setup guides.

| Key | Type | Default | Description |
|---|---|---|---|
| `mode` | string | `"local_ca"` | `"local_ca"`, `"self_signed"`, `"acme"`, or `"manual"` |
| `cert_file` | string | `""` | Path to PEM certificate file (for `manual` mode) |
| `key_file` | string | `""` | Path to PEM private key file (for `manual` mode) |
| `acme_email` | string | `""` | Email for Let's Encrypt registration (for `acme` mode) |
| `acme_domain` | string | `""` | Domain to issue certificate for (for `acme` mode) |
| `acme_challenge` | string | `"http01"` | ACME challenge type: `"http01"` or `"dns01"` |
| `min_version` | string | `"1.2"` | Minimum TLS version: `"1.2"` or `"1.3"` |

## `[audit]`

Audit log settings.

| Key | Type | Default | Description |
|---|---|---|---|
| `enabled` | bool | `true` | Enable the audit log |
| `retain_days` | int | `0` | Days to retain entries; `0` = retain indefinitely |

## `[privacy]`

PII redaction settings.

| Key | Type | Default | Description |
|---|---|---|---|
| `pii_redaction` | bool | `false` | Enable global PII redaction before model calls |
| `redact_names` | bool | `false` | Include name detection in redaction (higher false-positive rate) |
| `custom_patterns` | []object | `[]` | Additional regex patterns: `{ name, pattern, placeholder }` |

## Full example

```toml
[server]
port = 4200
log_level = "info"

[database]
url = "postgres://qorven:secret@localhost:5432/qorven?sslmode=disable"
pool_max = 20

[security]
encryption_key = "base64keyhere..."
ssrf_allowlist = ["*.google.com", "api.github.com"]

[auth]
jwt_secret = "base64secrethere..."
multi_tenant = false

[tls]
mode = "local_ca"
min_version = "1.2"
```

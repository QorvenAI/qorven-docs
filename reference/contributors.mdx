Qorven is built and maintained by a small core team and improved by contributors from the community. Every bug report, documentation fix, and code contribution matters.

## Contributors

See the full list of contributors on GitHub:

[github.com/qorvenai/qorven/graphs/contributors](https://github.com/qorvenai/qorven/graphs/contributors)

## How to contribute

Contributions are welcome. The full guide is in [CONTRIBUTING.md](https://github.com/qorvenai/qorven/blob/main/CONTRIBUTING.md) in the repository. The short version:

1. Search [existing issues](https://github.com/qorvenai/qorven/issues) before opening a new one.
2. For significant changes, open an issue first to discuss the approach.
3. Fork the repo, make your changes, and open a pull request against `main`.
4. All PRs require passing CI checks (`make build-backend` + `go test ./...`).

## Getting help and asking questions

For questions about using Qorven, visit [GitHub Discussions](https://github.com/qorvenai/qorven/discussions). This is the best place for:

- Setup and configuration questions
- Feature requests and ideas
- Sharing how you're using Qorven
- General questions that aren't bugs

For bugs and confirmed issues, use [GitHub Issues](https://github.com/qorvenai/qorven/issues).

## Code of conduct

All contributors are expected to follow the [Contributor Covenant Code of Conduct](https://github.com/qorvenai/qorven/blob/main/CODE_OF_CONDUCT.md).

Manage the Qorven gateway service

Usage:
  qorven gateway [command]

Available Commands:
  install     Install as systemd user service
  start       Start gateway in background
  status      Show gateway status
  stop        Stop the running gateway
  uninstall   Remove systemd service

Flags:
  -h, --help   help for gateway

Global Flags:
  -o, --output string   Output format: table, json, yaml (default "table")
      --server string   Gateway URL (env: QORVEN_SERVER)
      --token string    Auth token (env: QORVEN_TOKEN)
  -v, --verbose         Verbose output
  -y, --yes             Skip confirmation prompts

</Info>

## Anatomy of a command

```bash
qorven [global flags] <command> [subcommand] [flags] [args]
```

Most commands follow the **list / get / create / update / delete** pattern:

```bash
qorven agents list                    # all agents for this tenant
qorven agents get b2a19...            # one agent
qorven agents create --name Prime …   # create
qorven agents update b2a19 --model …  # update
qorven agents delete b2a19            # delete
```

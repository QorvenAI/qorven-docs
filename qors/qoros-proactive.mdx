Proactive mode (QOROS) was a V1 feature that triggered agents on a timer to act without being prompted. In V2, this is replaced by scheduled cron tasks, which are more flexible and give you full control over when and how often agents run.

See [Cron Scheduling →](/workflows/cron) to set up any agent to run automatically on a schedule.

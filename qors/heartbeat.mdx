Heartbeat was a V1 feature for periodic agent self-checks — agents would wake on a fixed interval, review their state, and report back. It has been replaced by Scheduling, which is more flexible and covers the same use cases. Use a cron schedule to run any agent task on a timer: status summaries, health checks, daily briefings, or anything else that should happen automatically. See [Cron Scheduling](/workflows/cron) to set it up.

Dream mode was a V1 feature that ran agents overnight to consolidate memories and surface patterns from recent activity. This has been replaced by automatic memory compaction, which runs continuously in the background without requiring a dedicated overnight window. See [Memory Compaction](/memory/compaction) for how agents consolidate context today — it covers the same ground as dream mode, with no scheduling required on your part.
